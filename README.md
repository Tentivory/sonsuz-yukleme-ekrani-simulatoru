# Sonsuz Yükleme Ekranı Simülatörü

Bu proje, insanlığın en büyük teknolojik başarısıdır. Asla bitmeyen, ama her an bitmek üzere olan bir yükleme ekranı. Evrenin sırlarını çözerken sizi bekletir.

## Özellikler
- %99.99 yüklenmiş gibi görünür
- Felsefi mesajlar basar
- RAM'inizi yemez, ruhunuzu yer
- Ctrl+C ile durdurulabilir (ama ruhunuz durmaz)

## Kurulum
```bash
python3 sonsuz_yukleme.py
```

## Uyarı
Bu programı çalıştırdıktan sonra hayatınızı sorgulayabilirsiniz. Sorumluluk kabul edilmez.
